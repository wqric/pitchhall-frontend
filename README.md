# PitchHall Frontend

Клиентское веб-приложение для интерактивного симулятора публичных выступлений **PitchHall**.

Интерфейс спроектирован строго в соответствии с дизайн-системой из Figma (File Key: `HweTnx5zuELVhtLfLwbYXk`), адаптирован под темную тему и воспроизводит опыт выступления перед живой аудиторией.

---

## Стек технологий

* **Vue 3** (`<script setup>`, Composition API)
* **Vite** — быстрый бандлер и dev-сервер
* **Tailwind CSS** — утилитарные стили с кастомными дизайн-токенами из Figma
* **Lucide Icons** (`lucide-vue-next`)
* **Web Speech API** — распознавание речи спикера в реальном времени
* **HTML5 Audio API** — очередь и динамическое воспроизведение голосовых реплик жюри

## Быстрый запуск и локальная разработка

### 1. Клонирование репозитория
```bash
git clone https://github.com/wqric/pitchhall-frontend.git
cd pitchhall-frontend
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Настройка окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```

В dev-режиме Vite автоматически проксирует запросы к бэкенду на `http://localhost:8000`:
* `/api/*` $\to$ `http://localhost:8000/api/*`
* `/static/*` $\to$ `http://localhost:8000/static/*`

### 4. Запуск dev-сервера
```bash
npm run dev
```
После запуска откройте браузер по адресу: **`http://localhost:5173`**.

### 5. Сборка для продакшна
```bash
npm run build
```
Готовая сборка будет находиться в директории `dist/`.

## Пользовательский сценарий (User Flow)

1. **SetupView (Подготовка)**:
   * Пользователь вводит или редактирует текст доклада.
   * Система автоматически рассчитывает количество слов и время выступления (~130 слов в минуту).
   * Кнопка «Выйти на сцену →» переводит спикера к суфлеру.

2. **TeleprompterView (Выступление)**:
   * Отображается крупный текст доклада с акцентом на активный абзац.
   * Запускается таймер времени речи.
   * Индикатор активного микрофона фиксирует голос спикера через Web Speech API.
   * При нажатии «Завершить доклад» текст отправляется на бэкенд (`POST /api/analyze`).

3. **AuditoriumStage (Секция Q&A)**:
   * Зрительный зал в 2 ряда ожидает окончания доклада.
   * Персонаж жюри плавно поднимает руку (`hand-raised`).
   * Над спикером раскрывается `SpeechBubble` с его ролью (`[Скептик]`, `[Теоретик]`, `[Новичок]`).
   * Воспроизводится аудиодорожка вопроса, в бабле пульсируют звуковые бары.
   * По завершении реплики персонаж опускает руку, бабл скрывается, через 1.5 секунды очередь переходит к следующему вопросу комиссии.
   * Доступна кнопка ручного перехода «Следующий вопрос →».
